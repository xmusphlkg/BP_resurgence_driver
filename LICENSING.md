Custom analysis code in this repository is released under the MIT License unless
otherwise noted by a file-level notice.

Manuscript text, rendered figures, figure source data, derived aggregate tables
and model summaries are provided for scholarly review and reproducibility of the
associated analysis. Reuse of third-party source data is governed by the terms
of the original data providers.

Raw or local third-party source snapshots without established redistribution
permission are not part of the public release. The public package instead
provides source identifiers, URLs, access dates, processing scripts and
shareable derived aggregates sufficient to audit the analysis provenance.
