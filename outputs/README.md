# Generated results

This directory contains compact model-generated outputs and processed aggregate results used by the public analysis code.

It deliberately excludes manuscript-facing assets, submission and peer-review records, internal audit outputs, raw third-party data, logs, compiled binaries, and large draw-level artefacts.


## Figure 1 source data

`figure_data/` contains the frozen aggregate CSV inputs required by
`script/figures/figure_1_global_trends.R`: the nine-country monthly context
series and the three baseline comparators per country. The companion metadata
file records row counts and SHA-256 checksums. Rendered manuscript figures and
private upstream regeneration inputs remain excluded.
